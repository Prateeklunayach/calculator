College Project Presentation Summary

Full Working Scientific & Converter BODMAS Parser Engine Vanilla JS + CSS3

1. Project Overview

OmniCalc Pro is an enterprise-grade computational web application developed for academic demonstration. It integrates advanced parsing algorithms, precision arithmetic handling, multi-system radix conversions, and unit transformations within a responsive modern user interface.

2. Key Architectural Highlights

  • Expression Parsing & AST Engine: Evaluates complex algebraic expressions observing standard mathematical order of precedence (BODMAS/PEMDAS) with nested parentheses and trig functions.
  • Floating-Point Precision Guard: Overcomes binary IEEE 754 precision artifacts (e.g. 0.1 + 0.2 = 0.3 instead of 0.30000000000000004).
  • Scientific Functions Suite: Full trigonometry, inverse trig, hyperbolic, logarithms (natural, base 10, base 2), powers, roots, factorials, and fundamental mathematical constants.
  • Programmer Mode: Real-time conversion across Hexadecimal (HEX), Decimal (DEC), Octal (OCT), and Binary (BIN) with bitwise operations (AND, OR, XOR, NOT, LSH, RSH).
  • Multi-Dimensional Unit Converter: Length, mass, temperature, digital data units, speed, area, and time with dynamic reference formulas.
  • User Experience Excellence: Custom Web Audio API feedback, glassmorphism UI, 5 dynamic themes, persistent history via LocalStorage, and complete keyboard accessibility.

3. Presentation Tips for Defense

Demonstrate the live expression preview, switch between DEG and RAD to evaluate sin(30) (0.5 vs -0.988), show keyboard operations, and toggle into Programmer mode to show instant live binary byte conversions.
